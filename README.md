# FunnelIQ

### Marketing Attribution & ROI Command Center

**[Open Live Dashboard ↗](https://harsha-funneliq.streamlit.app)**

Built around **50,000 users and 100,000+ touchpoints** to demonstrate multi-touch attribution, journey analytics and budget sensitivity analysis.

## Key capabilities

- Last-touch, linear and time-decay attribution
- Channel ROI, CAC and revenue contribution
- Acquisition funnel and regional performance
- Top customer journey paths
- Budget reallocation simulator
- CSV and Excel executive exports
- Interactive filters for region and device

## Technology

Python • Streamlit • pandas • NumPy • Plotly • openpyxl

## Data disclosure

All acquisition and revenue data are synthetic. Attribution and reallocation outputs are analytical scenarios, not causal claims.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
